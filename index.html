GitHub Sync Setup

Your progress is stored in a GitHub Gist. Enter a Personal Access Token once per device to enable saving.

  1. Go to github.com → Settings → Developer settings → Personal access tokens → Tokens (classic)
  2. Click Generate new token (classic)
  3. Set an expiry, tick the gist scope only
  4. Copy the token and paste it below
